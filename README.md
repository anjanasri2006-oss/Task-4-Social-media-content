# 📱 Task 04 — Social Media Content Calendar & Copy

## 📌 Project Overview

This project was completed as part of **SkillCraft Technology Task 04**.

The project focuses on creating a professional **one-week Social Media Content Calendar and Copy** for a fictional SaaS brand called **FlowSync**.

The campaign is designed for **LinkedIn and Twitter/X** and includes educational, promotional, and engagement-focused content.

---

## 🏢 Brand Overview

**Brand:** FlowSync  
**Product:** Async Collaboration Software for Remote Teams  
**Industry:** SaaS / Productivity  
**Platforms:** LinkedIn & Twitter/X

FlowSync is a fictional SaaS product designed to support asynchronous collaboration for remote and hybrid teams.

### Target Audience

- Remote and hybrid team leads
- Startup founders
- Operations managers
- Companies with 10–200 employees

### Brand Voice

The brand voice is:

- Confident
- Helpful
- Lightly witty
- Professional and approachable

## 🎯 Campaign Goal

The main goal of the campaign is to:

- Build credibility around async work culture
- Educate audiences about asynchronous collaboration
- Promote FlowSync's key features
- Encourage social media engagement
- Drive free-trial signups

### 📢 Promotional Content

### 💬 Engagement Content

Engagement posts encourage audiences to:

- Participate in discussions
- Answer questions
- Tag teammates

---

## 🚀 Featured Social Media Posts

### Post 1 — Why Async Updates Save Meetings

An educational post explaining how written asynchronous updates can help reduce unnecessary status meetings and create more focused work time.

### Post 2 — Smart Status Digests

A promotional feature spotlight introducing FlowSync's Smart Status Digests, which summarize project updates such as completed tasks, blockers, and decisions.

### Post 3 — Tag a Teammate

An engagement-focused post discussing meeting culture and encouraging audiences to share their experiences with unnecessary meetings.

### Post 4 — More Meetings = More Alignment

A myth-busting educational post discussing how written and searchable information can support team alignment.

### Post 5 — Limited-Time Free Trial Extension

A promotional post announcing a limited-time extension of the FlowSync free trial and encouraging potential users to try the product.
